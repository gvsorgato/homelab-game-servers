# Game Servers Infra

Documentação da administração de servidores de jogos multiplayer, hospedados 
em ambiente próprio desde 2019.

## Servidores documentados
- [Minecraft](./minecraft/README.md)
- [Terraria](./terraria/README.md)

## Ambiente geral
- **Virtualização**: VirtualBox, VM Ubuntu Server 24.04 LTS
- **Rede**: IP fixo, port forwarding com portas customizadas
- **Backup**: cópia manual do mundo para Google Drive antes de reconstruções
